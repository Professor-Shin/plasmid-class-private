# ที่มาของ `Plasmid vs Chromosome — ผลรันเต็มสเกลบน CU-AIM.pptx`

สไลด์ถูกสร้างด้วยสคริปต์ ไม่ได้วางมือ เพื่อให้แก้ตัวเลขแล้วสร้างใหม่ได้ทั้งชุด
เมื่อ `server/logs/report_*.md` ออกมาแล้ว (สไลด์ 10 · 12 · 13 ยังรอผลอยู่)

```bash
python3 build.py \
  "../Plasmid vs Chromosome — ตอบความเห็นผู้เชี่ยวชาญ.pptx" \
  "../Plasmid vs Chromosome — ผลรันเต็มสเกลบน CU-AIM.pptx" \
  /tmp/deck-work
```

| ไฟล์ | หน้าที่ |
|---|---|
| `ci.py` | สี ฟอนต์ กริด และรูปทรงพื้นฐานตาม The Siwak System CI |
| `blocks.py` | บล็อกสำเร็จรูป — แถวการ์ด ตาราง ตัวเลขใหญ่ สองคอลัมน์ ผังงาน |
| `build.py` | เนื้อหาของแต่ละสไลด์ + การประกอบไฟล์ .pptx |

อาร์กิวเมนต์แรกคือสไลด์ชุดเดิม ซึ่งถูกใช้เป็นต้นแบบของ theme / master / โลโก้
เท่านั้น สไลด์ทั้งหมดถูกเขียนใหม่

**หมายเหตุเรื่องฟอนต์** ชุดเดิมฝังฟอนต์แบบ subset มาจาก Google Slides คือมีเฉพาะ
ตัวอักษรที่สไลด์ชุดเดิมใช้ พอใส่ข้อความใหม่ ตัวอักษรที่ไม่มีใน subset จะกลายเป็น
สี่เหลี่ยมว่าง (เจอจริงกับคำว่า ORF และ A100) `build.py` จึงถอดการฝังฟอนต์ออก
แล้วให้ PowerPoint / Google Slides ไปใช้ Kanit กับ Noto Sans Thai ที่ติดตั้งไว้แทน
ทั้งสองตัวเป็น Google Fonts
